ABSTRACT

The Student Grade Calculator is a mobile application developed using Flutter to calculate and evaluate a student's academic performance. The main objective of this project is to provide a simple, fast, and user-friendly platform for students and teachers to calculate total marks, average marks, percentage, and corresponding grades.

The application allows users to enter marks obtained in different subjects. Based on the entered marks, the system automatically calculates the total and average and assigns a grade according to predefined grading criteria. The application provides an easy-to-understand interface and displays the results clearly.

This project demonstrates important Flutter concepts such as widgets, layouts, user input handling, state management, validation, and event handling. It also helps in understanding how mathematical calculations and conditional logic can be implemented in a mobile application. The Student Grade Calculator can be further enhanced by adding student profiles, grade history, GPA calculation, data storage, result sharing, and graphical performance analysis.
